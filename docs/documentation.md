# Документация расширения VS Code для TODO
## 1. Задачи
- Плагин генерирует текстовый файл с заметками
- Строка исходного кода копируется в этот файл, если она следует после `TODO`.
- Для каждого исходного кода может существовать не более одного файла с заметками(в директории ./notes/notes-<filename>.txt)
- По сочетанию клавиш `Ctrl + Alt + l` создается новый файл с заметками
- В файле заметками строки заметок имеют ссылку к файлу и строке, в которой они написаны. В файле с заметками она отображается как `TODO: <...> -> <filename>:<line_index>`
- Если заметка была удалена или измененна, в файле с заметками она перечеркивается
- В файле с заметками можно добавить свои записи, которые не будут соответствовать формату `TODO`, и они будут сохраняться при любом изменении исходного файла

## 2. Основные компоненты кода
### Тип Todo

```typescript
type Todo = {
    text: string;
    line: number;
};
```
Описывает найденную заметку:
- `text` — текст TODO
- `line` — номер строки, в которой задача находится в исходном документе

### Функция `activate`

VS Code вызывает её при активации расширения.
Внутри функции регистрируются:
- команда для создания файла заметок
- обработчик изменений текста
- механизм синхронизации задач
- оформление зачёркнутых записей
- провайдер ссылок на исходный код

### Функция `getNotesUri`
`function getNotesUri(document: vscode.TextDocument): vscode.Uri`

Определяет путь к файлу заметок для конкретного исходного документа

Функция использует:
- директорию исходного файла
- имя исходного файла
- папку `notes`
- префикс `notes-`

### Функция `syncTodos`
`function syncTodos(document: vscode.TextDocument)`

Она выполняет следующие действия:
1. Проверяет, подходит ли документ для обработки
2. Получает путь к файлу заметок
3. Находит все TODO в исходном коде
4. Читает существующие записи
5. Сопоставляет задачи из кода с задачами в заметках
6. Обновляет номера строк у найденных совпадений
7. Помечает несопоставленные активные записи `~~`
8. Добавляет новые заметки
9. Записывает обновлённый список в файл
10. Обновляет оформление открытых файлов заметок

Личные записи, которые не распознаются как задачи, сохраняются без изменений

### Функция `parseTodo`
`function parseTodo(line: string)`

Преобразует строку из файла заметок в структурированную запись TODO.
Если строка не соответствует ожидаемому формату, функция не распознаёт её как TODO.

### Функция `identity`
`function identity(text: string, file: string)`

Создаёт id для сопоставления задач.
Идентификатор формируется из имени файла и текста задачи

### Функция `updateStrikethrough`
`function updateStrikethrough(editor: vscode.TextEditor)`

Отвечает за визуализацию зачёркнутых записей.
Она находит строки, которые начинаются и заканчиваются маркерами `~~`, и применяет к ним оформление через API VS Code.

### Функция `refreshOpenNotes`
`function refreshOpenNotes()`

Обновляет оформление открытых файлов заметок.
Это необходимо, чтобы изменения в списке задач отображались в уже открытых редакторах без необходимости закрывать и повторно открывать файл.

### Обработчик `onDidChangeTextDocument`

Следит за изменениями текста в открытых документах.
Чтобы не запускать синхронизацию слишком часто, используется задержка — 1500 миллисекунд.

Если пользователь продолжает редактирование, предыдущий таймер отменяется и запускается заново. После паузы вызывается `syncTodos`.

### `DocumentLinkProvider`
Отвечает за создание кликабельных ссылок в файлах заметок.

Он ищет текст в формате:

```
example.ts:10
```

Затем определяет путь к исходному файлу и создаёт ссылку на соответствующую строку.
